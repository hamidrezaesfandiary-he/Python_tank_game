## About the Game

In this game, you control a tank and shoot falling soldiers. The goal is to destroy the soldiers and get a higher score.
## Features

* Tank movement with arrow keys
* Shooting bullets using the Space key
* Falling soldiers
* Bullet and soldier collision detection
* Score system
* Custom images and background
* Random soldier positions and speeds
## Controls

| Key         | Action     |
| ----------- | ---------- |
| Up Arrow    | Move Up    |
| Down Arrow  | Move Down  |
| Left Arrow  | Move Left  |
| Right Arrow | Move Right |
| Space       | Shoot      |
## Technologies

* Python

## How to Run

1. Make sure Python is installed.
2. Install Pygame:

`pip install pygame`
3. Put the game images in the correct folder.
4. Run the Python file:

`python main.py`
## Game Logic
The game includes:

* Player movement
* Bullet movement
* Falling soldiers
* Collision detection
* Score tracking
* Random soldier spawning

The score increases when a bullet hits a soldier and decreases when a soldier reaches the bottom or collides with the tank.
